# My Website

A starter multi-page website designed for GitHub Pages.

## Sections

1. Home
2. Alts Dashboard
3. Stat Calculator
4. Yen Calculator
5. Requests

## Folder structure

- `index.html` — Home page
- `alts.html` — Alts Dashboard
- `stats.html` — Stat Calculator
- `yen.html` — Yen Calculator
- `requests.html` — Requests page
- `css/style.css` — Shared website styling
- `js/main.js` — Shared JavaScript
- `assets/images/` — Images can be added here later

## GitHub Pages

Upload the contents of this folder to a GitHub repository, then enable GitHub Pages using the repository's `main` branch and root (`/`) folder.
